# Chess

A full stack chess engine built using Java (Spring Boot) and Angular.
I'm building it as a learning project to practice DSA, OOP, system design, and full-stack development.

## Tech Stack
- *Backend*: Java, Spring Boot, Maven
- *Frontend*: Angular, TypeScript, SCSS

## Features
### Completed
- [x] Chessboard rendered with initial board pieces.
- [x] Game state saved
- [x] Piece movement logic
- [x] Turn based movement
- [x] Button to reset board
- [x] Special rule sets
  - [x] Pawn promotion
  - [x] Castling
  - [x] En Passant
- [x] UI and sounds
- [x] Capture logic

### In Progress
- [ ] Back move and notations
- [ ] Chess engine opponent  
  - [ ] Evaluation bar

### Future Features
- [ ] Player vs computer mode

## DSA concepts used

- *Arrays, 2D matrices*
- *ArrayList*
- *HashMaps*

I'm building this project in multiple phases
